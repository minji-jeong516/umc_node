# 6주차 API 미션

## 미션 1
기존에 구현했던 API의 Repository 함수들을 Prisma ORM을 이용하도록 변경

## 미션 2
내가 작성한 리뷰 목록 조회 API를 구현

## 미션 3
내가 진행 중인 미션 목록 조회 API를 구현

## 미션 4
내가 진행 중인 미션을 진행 완료 상태로 변경하는 API를 구현

## 구현 내용
- Prisma ORM 적용
- Repository 계층 Prisma 기반으로 수정
- 리뷰 목록 조회 기능 구현
- 진행 중인 미션 목록 조회 기능 구현
- 미션 완료 처리 기능 구현
